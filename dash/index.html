GitHub connection

The site is hosted on GitHub Pages, which serves files but can't run any code of its own. So Save works by committing straight to the repository from this browser — which needs a GitHub token with permission to write to it. The token is stored only in this browser and never leaves it except to talk to GitHub.

Either kind of GitHub token works:

Classic (simplest) — create one here with the public_repo scope ticked. Nothing else to configure.

Fine-grained (tighter, more fiddly) — create one here, then set both: “Repository access” → Only select repositories → pick this repo, and “Permissions” → Contents: Read and write. Missing either one gives a 403.
Must match the branch the Pages workflow deploys from.
